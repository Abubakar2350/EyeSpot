#
# Ultralytics would pull torch in on its own, but the default PyPI wheel bundles

# "+cpu" build — which exists only on the PyTorch index — is named explicitly.
#
# On a machine with an NVIDIA GPU, install the CUDA build instead:
#   pip install torch torchvision --index-url https://download.pytorch.org/whl/cu124
